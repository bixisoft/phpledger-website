Basic Usage 
<?php
require_once 'config/database.php';
require_once 'classes/Ledger.php';

// Create a new ledger instance
$ledger = new Ledger($pdo);

// Create accounts
$assets = $ledger->createAccount('Assets', 'ASSET');
$revenue = $ledger->createAccount('Revenue', 'REVENUE');

// Record a transaction
$transaction = $ledger->createTransaction([
    ['account_id' => $assets, 'debit' => 1000, 'credit' => 0],
    ['account_id' => $revenue, 'debit' => 0, 'credit' => 1000]
], 'Sale of products');

echo 'Transaction recorded successfully!';
?>

API Reference

Clean, intuitive API for all your accounting needs.

createAccount($name, $type, $currency = 'USD')

Creates a new account in the ledger.

$accountId = $ledger->createAccount('Cash', 'ASSET', 'USD');

createTransaction($entries, $description = '')

Records a transaction with balanced debit and credit entries.

$transactionId = $ledger->createTransaction([
    ['account_id' => $cashAccount, 'debit' => 500, 'credit' => 0],
    ['account_id' => $revenueAccount, 'debit' => 0, 'credit' => 500]
], 'Sale received in cash');

getAccountBalance($accountId)

Retrieves the current balance of an account.

$balance = $ledger->getAccountBalance($accountId);

getTransactionHistory($accountId, $limit = 50)

Gets transaction history for an account.

$history = $ledger->getTransactionHistory($accountId, 100);
